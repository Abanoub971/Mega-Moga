# Brand Naming

Goal: end with **one final name**, a short list of runners-up, and the evidence behind the choice. Not a list of 100 ideas for the user to sort through.

Reply in the user's language. For Egyptian users, write in Egyptian Arabic and keep names in Latin script with Arabic spelling beside them.

## Lessons this skill is built on

These came from a real naming session that went through four rejected rounds before landing:

- **Calibrate taste before generating.** Ask for 3 names the user loves (from competitors or anywhere). One answer saves several rejected rounds.
- **A name the user has to have explained is weak.** Heritage words that need a paragraph of history (Kadr, Alhazen, Mashrabiya) got rejected. A name should land on first hearing; the story is a bonus.
- **Fewer, better.** Show 10 or fewer scored names in chat. Put large banks (hundreds of variations) in a separate page or file.
- **Check before recommending.** Every name you recommend needs a web check for same-name companies in the same category and region. Say plainly which names you checked and which you didn't.
- **Say the bad news yourself.** Hidden English words, slang, weapon brands and political symbols kill names after launch. Find them before the user does.

## Step 0: Calibrate taste (do this first, with AskUserQuestion)

In the session this skill came from, four rounds of names were rejected. Then a three-question multiple-choice check found the real problem in under a minute: the user wanted **sound and attitude**, not meaning. Ask these before generating anything:

1. **What feel?** Offer 4 example clusters taken from names the user already likes or listed. For example: short and bold (Stink / Rogue / JOE), quirky and elegant (Somesuch / Prettybird), heavy with a stance (Partizan / ICONOCLAST), local and authentic (Bedouin / Tasweer).
2. **What language?** Global English / easy Arabic / coined word / any language as long as it sounds strong.
3. **When they reject a name, ask why.** Offer: the sound, too historical, the meaning doesn't land, can't say why. The answer tells you which way to steer.

If the user picks "short and bold" + "sound": go for 1–2 syllables, hard stops (K, T, D, G, R) and back vowels (o, u). Prefer words that describe bad behaviour and wear it proudly (rogue, stink, rude, knucklehead). Drop the story-first approach.

## Step 1: Brief (one question at most)

Collect, or assume and state:

| Field | Default if unknown |
|---|---|
| Category and what the company sells | Take it from the conversation |
| Home market and target markets | MENA + global clients |
| Positioning (premium / bold / warm / technical) | Premium creative |
| Names the user loves or hates | Ask for 3 names they love. This is the one question worth asking |
| Languages the name must survive | Egyptian, Gulf, Levantine, Maghrebi Arabic + English + French + Spanish + Portuguese + German |

## Step 2: Naming territories

Pick 5–7 territories before generating. Each territory is a source of meaning, for example:

- Nature: animals, birds, sea, weather
- Sky: stars (many global star names are Arabic: Aldebaran, Nashira, Altair), cosmic phenomena
- Ancient and local heritage: ancient Egyptian, Nahuatl, classical Arabic
- Craft terms from the category (for a film company: frame, light, lens)
- Attitude words: short words with personality, like Stink or Rogue
- Meaningful numbers: dates, coordinates, technical values with a real story

For every concept, translate it across the target languages (Arabic MSA, local dialect, German, French, Spanish, Mexican/Nahuatl, Portuguese, Latin/Greek, ancient local language). Variations across languages are where unusual, ownable names come from.

## Step 3: Generate across the trademark spectrum

Aim for 100+ raw candidates, mixed across the spectrum. Stronger protection is at the top:

1. **Fanciful / coined:** invented word. Easiest to protect, needs marketing to build meaning.
2. **Arbitrary:** real word from an unrelated world (Apple for computers, Bennu for a film company). Usually the best balance.
3. **Suggestive:** hints at the benefit. Protectable, but weaker.
4. **Descriptive:** says what you do ("Cairo Video Production"). Avoid. Hard to protect and easy to forget.

## Step 4: Hard gates (any fail = cut)

| Gate | Test |
|---|---|
| G1 Conflict | No company with the same or near-identical name in the same category and region. Web search `"<name> Films"`, `"<name> Studio"`, `"<name> Production"`, `"<name>" <category> <region>` |
| G2 Bad meaning | No negative meaning, slang, or embedded rude word in any target language or dialect. Read it as an English speaker would (Haboob hides "boob"; Nube reads as "noob"; Sirio means "Syrian" in Spanish; Nadir means "lowest point") |
| G3 Sound | Arabic speakers must say it right: avoid P and V (often said as B and F). Foreigners must say it right: avoid ع ح خ ق غ ض ظ. Max 3 syllables |
| G4 Association | Not a weapon, military, political or religious symbol, and not a famous brand in another category (Caracal = UAE arms maker, Anka = Turkish military drone, Simorgh = Iranian rocket, hoopoe = Israel's national bird, Thuraya = satellite phone company, Lucero = famous singer) |
| G5 Burned | Not a category cliché. MENA: Falcon, Oasis, Desert, Dune, Pharaoh, Ra, Habibi, Yalla. Production: Create, Central, Circle, Chrome, Reverie, Phoenix in any European form |

## Step 5: Score the survivors (100 points)

| Criterion | Points | What earns full marks |
|---|---|---|
| Ownability | 20 | Arbitrary or coined, no hits in web search, likely trademarkable |
| Ease | 15 | Passes the phone test: say it once, a stranger spells it right |
| Meaning | 15 | A true story that fits in one sentence and relates to what the company does |
| Sound | 15 | 2–3 syllables, clear rhythm, ends on an open vowel. Back vowels and voiced stops (B, D, G) feel strong; front vowels and soft fricatives (F, S) feel light |
| Strategic fit | 15 | Fits the positioning, and works outside the home market |
| Identity potential | 10 | An obvious logo idea and a clean social handle |
| Founder conviction | 10 | The user reacted positively to it. Don't overrule a name the user loves unless it fails a gate |

Show a table: name, Arabic spelling, pronunciation, meaning, score per criterion, total, check status (✓ checked and clear / ⚠ conflict found / ? not checked).

## Step 6: Stress-test the top 3

- Read it aloud in Egyptian, Gulf and Levantine Arabic. Does it sound like any word?
- Read it as English, French and Spanish speakers would. Any hidden word inside?
- Misspelling test: what will people type into Google or Instagram?
- Fact-check the story. If sources disagree, say so and phrase the story carefully.
- Domain and handles: try `<name>.com`, `<name>films.com`, `<name>.studio`, `<name>.film`, `@<name>films`. If the session can't reach domain lookups, say so and give the user the list to check.

## Step 7: Deliver

1. **Final name** in one line, with the total score.
2. **Why it won**, compared with the runner-up.
3. **Name architecture:** brand name, legal name (`<Name> Films` / `Studio` / `Production`), Arabic spelling, pronunciation, handle.
4. **Story in one sentence** for clients.
5. **3–5 taglines.**
6. **Visual direction** in two lines: do / don't.
7. **Risks** you found, and what you didn't check.
8. **Next steps to lock it:** trademark search in classes 41 (production and entertainment) and 35 (advertising) in each registration country (Egypt: ITDA; UAE: Ministry of Economy; KSA: SAIP), buy the domain, reserve handles, have a lawyer review before filing.

Remind the user that a web search is not a trademark search.
