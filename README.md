# «خيط واحد» — فيلم تعريفي لخدمة القديس بولس القبطية (30 ثانية)

**الفيديو النهائي:** [`output/saint-paul-one-thread-30s.mp4`](output/saint-paul-one-thread-30s.mp4): ‏1920×1080، ‏30fps، ‏H.264 + AAC، ‏30.0 ثانية بالضبط، علو الصوت حوالي ‎-15 LUFS.

## الفكرة الإخراجية

الفيلم كله **خط ضوء ذهبي واحد لا ينقطع**. يخرج من لهب شمعة ويتحرك من اليمين إلى اليسار في اتجاه الكتابة العربية، كأنه رسالة تُكتب مثل رسائل بولس الرسول. وفي طريقه يتحول:

| الزمن | الخيط يصير… | المعنى |
|---|---|---|
| 0–3 ث | لهب شمعة يصعد منه الخيط | **يبدأ بالإيمان** |
| 3–9 ث | كتاب مفتوح ← رف مكتبة ← شاشة درس | **ويُبنى بالمعرفة** (مكتبة تعليمية · مدرسة أونلاين) |
| 9–13 ث | نقطة ضوء جديدة تمد خيطها، فيتضفّر الخيطان تضفيرًا قبطيًا | **يجمع من يبدأ ومن يخدم** (القادمون الجدد والخدّام) |
| 13–17 ث | الخيط يصير نبض قلب | **ويمتد إلى من يداوي** (ذوو الخلفية الطبية) |
| 17–22 ث | الخيط يصعد ويرسم صليبًا قبطيًا كاملًا: ثلاث فصوص في كل ذراع | **حتى يصير استعدادًا للخدمة** |
| 22–24 ث | الكاميرا تبتعد وتكشف أن كل ما سبق كان خطًا واحدًا من الشمعة إلى الصليب، ونبضة ضوء تعبر الطريق كله | |
| 24–30 ث | الاسم، و«إيمان · معرفة · خدمة»، وآية ٢ تيموثاوس ٢: ١٥ | «مفصّلًا كلمة الحق **بالاستقامة**»: الخط المستقيم هو الآية نفسها |

**الصوت** مولَّد بالكامل بالكود ويحكي القصة نفسها. يبدأ بنغمة قرار ممتدة (إيسون) مع صوت جوقة واحد، ثم يصبحان صوتين عندما يلتقي الخيطان. يظهر **المثلث والناقوس**، وهما آلات الألحان القبطية، مع اجتماع الخيطين. عند نبض القلب يصمت اللحن ولا يبقى إلا القلب. مع رسم الصليب يتسارع الإيقاع ويتصاعد حتى ينفرج على سلم كبير، ثم ينتهي الفيلم بقفلة هادئة. أما خشخشة القلم فتتبع سرعة الخط الفعلية على الشاشة.

## التشغيل والتصدير

المتطلبات: Node 18+، ‏Python 3 مع numpy، ‏ffmpeg.

```bash
npm install                 # يثبّت playwright والخطوط
npx playwright install chromium   # مرة واحدة (إن لم يكن Chromium مثبتًا)
pip install numpy

npm run build               # يبني كل شيء → output/saint-paul-one-thread-30s.mp4  (~9 دقائق)
```

خطوات منفصلة:

```bash
npm run preview             # معاينة حية في المتصفح: http://127.0.0.1:5173/src/index.html (تشغيل + شريط تقديم)
node scripts/render.mjs --stills 3,12,21.5,28   # صور ثابتة للمراجعة السريعة في build/stills
node scripts/render.mjs     # الصورة فقط → build/video.mp4 + build/timeline.json
python3 scripts/audio.py    # الصوت فقط → build/audio.wav (يحتاج timeline.json)
```

## التعديل

- **كل النصوص** في `src/config.js`: العناوين، واسم الخدمة، والآية، والكلمة القبطية (اجعلها `''` لإخفائها).
- **التوقيتات**: جدول `ANCHORS` في `src/film.js` يحدد متى يصل الخط إلى كل محطة. الصوت يقرأ التوقيتات تلقائيًا من `build/timeline.json`، فيبقى متزامنًا.
- **توازن الصوت**: قاموس `GAIN` في `scripts/audio.py`.

## البنية

```
src/film.js        المحرك: المسار، الكاميرا، الرسم — كل إطار دالة في الزمن t
src/config.js      النصوص والألوان
src/index.html     صفحة المعاينة/التصدير
scripts/render.mjs Chromium (Playwright) → ffmpeg إطارًا بإطار
scripts/audio.py   الموسيقى والمؤثرات (numpy)
scripts/build.sh   البناء الكامل + الدمج وضبط علو الصوت
assets/fonts/      عارف رقعة (العناوين)، أميري (الآية)، نوتو كوفي (النصوص الصغيرة)، Noto Sans Coptic — كلها برخصة SIL OFL 1.1
```

## ملاحظات صريحة

- **الشعار الرسمي لم يُستخدم** لأنه لم يكن موجودًا في المستودع. الصليب القبطي في الفيلم مرسوم بالكود. لإضافة الشعار يمكن وضع صورته في البطاقة الختامية داخل `drawEndCard`.
- **لا يوجد تعليق صوتي.** أصوات تحويل النص إلى كلام بالعربية المتاحة هنا لا ترقى إلى نبرة خدمة كنسية، والنص المكتوب مع الموسيقى يكفي في 30 ثانية. يمكن تسجيل صوت بشري لاحقًا على العناوين نفسها.
- النص القبطي ⲡⲁⲩⲗⲟⲥ يعني «بولس». يُستحسن أن يراجعه أحد من الخدمة.
- الاسم مكتوب كما ورد في الطلب: «خدمة القديس بولس القبطية». عدّله من `config.js` إن كان الاسم الرسمي مختلفًا.
- الفيلم لا يحتوي على أي أرقام أو وعود أو معلومات غير ما ورد في وصف الخدمة.
